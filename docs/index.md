# Programme du cours

Ce cours part de zéro absolu et monte jusqu'aux concepts utilisés par les traders professionnels. Il est conçu pour être suivi dans l'ordre : chaque niveau s'appuie sur le précédent, et chaque niveau se termine par un examen.

## Comment travailler ce cours

1. **Suivez les niveaux dans l'ordre**, même si certains chapitres vous semblent déjà connus. Les quiz vous diront rapidement si vous pouvez accélérer.
2. **Faites les exercices avant de regarder les solutions.** La lecture passive ne crée aucune compétence.
3. **Passez l'examen de fin de niveau** et visez au moins 80 % avant de continuer.
4. **Aucun capital réel avant le niveau 9.** Le cours inclut une roadmap 30/60/90 jours qui encadre le passage du paper trading au réel.

## Le gabarit d'un chapitre

Chaque chapitre rédigé suit la même structure, sans exception :

- **La théorie**, expliquée depuis zéro, avec le vocabulaire anglais du métier conservé.
- **Des graphiques annotés** pour chaque concept visuel.
- **Un trade gagnant et un trade perdant décortiqués**, parce que les pertes enseignent autant que les gains.
- **Des exercices** avec solutions repliables.
- **Un quiz corrigé** pour valider le chapitre.
